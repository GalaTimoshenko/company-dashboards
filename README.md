# Сводки по компаниям на открытых данных

Одна страница на компанию: ключевые цифры, карта связей, путь компании, риски и возможности. Только открытые источники (ФНС, сайты компаний, СМИ), у каждой цифры есть год и ссылка. Факт и вывод на карте связей различаются: сплошная линия — факт, пунктир — мой вывод.

| Сводка | Ссылка |
|---|---|
| АиГринд — игровая студия | https://galatimoshenko.github.io/company-dashboards/aigrind/ |

Как делаю: вопрос руководителя → факты с источниками → таблицы → выводы → одна страница. Страницы статичные (HTML + d3.js), работают с телефона.
