# Сводки по компаниям на открытых данных

Одна страница на компанию: ключевые цифры, карта связей, путь компании, риски и возможности. Только открытые источники (ФНС, отчётность компаний, сайты, СМИ), у каждой цифры есть год и ссылка. Факты и мои выводы подписаны отдельно.

| Сводка | Ссылка |
|---|---|
| ЛУКОЙЛ — продажа зарубежного бизнеса после санкций | https://galatimoshenko.github.io/company-dashboards/lukoil/ |
| Зарубежнефть — ставка на Вьетнам | https://galatimoshenko.github.io/company-dashboards/zarubezhneft/ |
| АиГринд — игровая студия | https://galatimoshenko.github.io/company-dashboards/aigrind/ |
| Volve — финмодель месторождения (DCF, Excel) | https://galatimoshenko.github.io/company-dashboards/volve-dcf/ |

Как делаю: вопрос руководителя → факты с источниками → таблицы → выводы → одна страница. Страницы статичные (HTML + SVG), работают с телефона.
