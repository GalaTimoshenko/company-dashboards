# Сводки по компаниям на открытых данных

Одна страница на компанию: ключевые цифры, карта связей, путь компании, риски и возможности. Только открытые источники (ФНС, отчётность компаний, сайты, СМИ), у каждой цифры есть год и ссылка. Факты и мои выводы подписаны отдельно.
